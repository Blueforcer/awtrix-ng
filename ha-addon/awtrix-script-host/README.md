# AWTRIX Script Host

Runs the scripts of your AWTRIX NG clocks on Home Assistant, and the clocks show them. For ESP32
clocks, for example the Ulanzi TC001. The TC002 runs its own scripts.

After **Start**, **Open Web UI** shows a pairing code. Type it into the web UI of the clock under
**System → Script host**.
