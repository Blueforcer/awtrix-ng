# AWTRIX Script Host

Runs the scripts of your AWTRIX NG clocks in Home Assistant. The clock shows them in its rotation
and keeps its memory free for everything else.

For ESP32 clocks, for example the Ulanzi TC001. The TC002 runs its own scripts.
