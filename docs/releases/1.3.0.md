# AWTRIX NG 1.3.0

Release of 2026-11-27. Everything that changed since **1.2.3**.

### New

<!-- only esp32 esp32-s3 -->
* **Script host:** your scripts run on a computer in your network and use none of the clock's
  memory, so <!-- only esp32 -->a TC001<!-- /only --><!-- only esp32-s3 -->your clock<!-- /only -->
  runs almost any number of scripts. The clock shows them in its rotation as before. The script
  host installs on Windows, macOS, Linux and Raspberry Pi, as a Home Assistant app or with Docker.
  On Windows and macOS it is a program with an icon in the notification area or the menu bar. It
  starts when you sign in, and its menu shows the pairing code. You pair the clock once with a
  6-digit code. See [Script host](../guides/script-host.md).
* **AHT10 and AHT20 sensors** are found on the sensor bus, for temperature and humidity. See
  [Sensor bus](../reference/gpio.md#sensor-bus).
<!-- /only -->
<!-- only tc002 -->
* **Custom wake word sensitivity:** choose **Custom** under **Sensitivity** and enter a **Cutoff**
  from 0.30 to 0.99, for a finer step than the three levels. See
  [Start it with "Hey AWTRIX"](../guides/voice.md#start-it-with-hey-awtrix).
<!-- /only -->

### For script developers

* **Change an app's settings over MQTT:** `<prefix>/cmd/apps/<name>/config` for a script and
  `<prefix>/cmd/apps/builtin/<name>/config` for a built-in app take the same JSON as the web UI. The
  script needs no change. See [apps/&lt;name&gt;/config](../reference/mqtt.md#apps-name-config).

### Fixed

* **MQTT:** a broker that takes a few seconds to accept the login, such as the Home Assistant
  Mosquitto app, connects. The clock waits up to 10 seconds, and the display keeps running
  meanwhile.
<!-- only tc002 -->
* **Setup hotspot:** **Scan** lists the Wi-Fi networks nearby, so you no longer type the name by
  hand.
* **Wake word:** after a microphone error, **Status** says so instead of claiming the clock
  listens, and switching the wake word off and on tries again at once.
* **Microphone controller update** also runs on clocks whose controller has firmware V1.0.16.
* **Clock voice:** the built-in English voice is called Lumi, as in the shop.
* **Desktop installers:** the terminal installer on macOS starts again, and the installers show the
  USB error and stop after 30 seconds instead of trying forever. Get the installer again. See
  [Get the installer](../getting-started/tc002.md#get-the-installer).
<!-- /only -->
